# Simple Interest Calculator

This project is part of the **GitHub Final Project** assignment.  
It demonstrates a simple interest calculator built using **HTML, CSS, and JavaScript**.

## 📌 Purpose
The calculator computes **Simple Interest (SI)** based on user input values:
- Principal amount (P)
- Rate of interest (R)
- Time period in years (T)

The formula used is:
SI = (P × R × T) / 100

## 🧮 Features
- User-friendly input fields for principal, rate, and time
- Instant calculation of simple interest
- Displays both **Simple Interest** and **Total Amount**
- Input validation to prevent invalid entries
- Clean and responsive UI

## 🚀 How to Use
1. Enter the **principal amount**  
2. Enter the **rate of interest**  
3. Enter the **time period** in years  
4. Click **Calculate**  
5. The result will appear below the form

## 📝 Example
For:
- Principal = 1000  
- Rate = 5%  
- Time = 2 years  

Simple Interest = `(1000 × 5 × 2) / 100 = 100`  
Total Amount = `1100`
